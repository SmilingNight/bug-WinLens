# WinLens · 窗镜

轻量级 Windows 窗口 & 鼠标信息查看工具，单文件、零依赖、即开即用。

## 功能

- 实时显示鼠标屏幕坐标
- 显示鼠标相对于目标窗口的坐标
- 识别鼠标所在窗口的句柄、标题、类名、进程名、PID
- 识别当前光标类型（箭头、手型、等待、文本等）
- 显示目标窗口的位置、尺寸、四边坐标

## 快捷键 / 操作

| 操作 | 效果 |
|------|------|
| 移动鼠标 | 自动跟踪并刷新下方窗口信息 |
| 拖拽标题栏 | 移动工具窗口 |
| 点击 **FREEZE** | 冻结当前数据，停止刷新 |
| 再次点击 **FREEZE** | 恢复实时刷新 |
| 按 **F** 键 | 切换冻结 / 刷新 |
| 点击 **X** 或按 **Esc** | 关闭工具 |
